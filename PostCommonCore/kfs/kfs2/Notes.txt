GDT Entry Example (kernel code, flat model) = 0x00CF9A000000FFFF :

Limit Low  : 0xFFFF       ; Limit bits 0-15
Base Low   : 0x0000       ; Base bits 0-15
Base Middle: 0x00         ; Base bits 16-23
Access Byte: 0x9A         ; P=1, DPL=0, S=1, Type=0xA (code, execute/read)
Granularity: 0xCF         ; Flags 0xC (G=1 4 KB pages, D=1 32-bit) + limit bits 16-19 = 0xF
Base High  : 0x00         ; Base bits 24-31

Base  = 0x00000000
Limit = 0xFFFFF (20 bits). With G=1 it counts 4 KB pages: 0xFFFFF * 4 KB = 4 GB.
So the segment covers the whole 32-bit address space.
